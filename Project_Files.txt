📝 文件功能说明
-----------------------------------------------------------------

【数据处理】
dataset.py
  - ShapeReconstructionDataset: 数据集类
  - 支持训练/验证集加载
  - 自动数据增强（翻转、旋转、噪声）
  - 归一化处理

prepare_data.py
  - 3种数据准备方法：
    * synthetic: 生成合成数据（最快）
    * camera: 从摄像头采集（最真实）
    * existing: 从已有图像生成
  - 自动划分训练/验证集
  - 支持命令行参数

【模型定义】
model.py
  - SimpleReconstructionNet: 简单模型（~200K参数）
  - ReconstructionNet: U-Net模型（~500K参数，推荐）
  - ResNetReconstructionNet: ResNet模型（~800K参数）
  - 提供参数统计函数

【训练流程】
train_reconstruction.py
  - 完整训练流程
  - 组合损失函数（MSE + L1 + Edge）
  - TensorBoard日志
  - 学习率调度
  - 自动保存最佳模型
  - 支持断点续训

【测试评估】
test_reconstruction.py
  - 3种测试模式：
    * evaluate: 验证集评估
    * compare: 对比传统方法
    * demo: 实时演示
  - 量化指标计算
  - 对比图生成

【系统集成】
sensor_dl.py
  - SensorDL类：继承原Sensor
  - 兼容原有API
  - 支持动态切换方法
  - 自动加载模型

【自动化】
quick_start.sh
  - 一键启动脚本
  - 5种执行模式
  - 自动环境检查
  - 交互式菜单

最快路径（2小时）：

  bash quick_start.sh
  选择：1

手动执行：
  cd shape_reconstruction
  python prepare_data.py --method synthetic --num_samples 1000
  python train_reconstruction.py --model simple --epochs 30
  python test_reconstruction.py --mode evaluate
