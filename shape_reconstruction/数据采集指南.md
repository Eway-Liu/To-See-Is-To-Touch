# 触觉传感器数据采集指南

## 数据集用途

采集的数据用于训练深度学习模型，学习从差分图像预测3D形状（高度图）。

**数据配对：**
- 输入：diff_images（差分图像）
- 标签：height_maps（高度图，由传统方法生成作为伪标签）

## 核心采集原则

### 1. 多样性原则（最重要）

模型的泛化能力取决于训练数据的多样性。

#### 物体形状多样性
- ✅ **球形物体**：弹珠、乒乓球、网球等不同大小的球
- ✅ **圆柱形物体**：笔、螺丝刀、管道等不同直径的圆柱
- ✅ **平面物体**：手指、手掌、卡片、积木等
- ✅ **不规则形状**：钥匙、螺母、橡皮、日常小物品
- ✅ **不同曲率**：从尖锐（笔尖）到平坦（书本）

#### 接触位置多样性
- 传感器中心区域
- 边缘区域
- 不同象限
- 多点同时接触

#### 接触力度多样性
- 轻触（刚接触，高度 0.1-0.5mm）
- 中等压力（高度 0.5-2mm）
- 较大压力（高度 2-5mm）
- **注意**：不要过度按压损坏传感器

#### 接触角度多样性
- 垂直接触
- 倾斜接触（不同角度）
- 边缘接触
- 滚动接触

### 2. 数据质量原则

#### 确保有效接触
- 每个样本应该有明显的接触信号（max_height > 0.05mm）
- 避免保存无接触的"空白"数据
- 脚本会自动过滤无效样本

#### 避免重复样本
- 不要在同一位置保持不动
- 脚本会自动过滤相似的连续帧
- 手动保存时确保有明显变化

#### 保持环境稳定
- ⚠️ **光照稳定**：采集过程中不要改变光源
- ⚠️ **传感器固定**：不要移动传感器
- ⚠️ **参考图像不变**：中途不要重启程序

### 3. 数量原则

#### 最小数量要求
- **最少**：500 个样本（可以开始训练，但效果有限）
- **推荐**：1000-2000 个样本（较好效果）
- **理想**：3000+ 个样本（最佳效果）

#### 分批采集
可以分多次采集，数据会自动累加：
```bash
# 第一次采集
python data_preparation.py --auto_ref
# 采集 200-300 个后按 'q' 退出

# 第二次继续采集
python data_preparation.py --auto_ref
# 继续采集，编号自动续上
```

### 4. 平衡性原则

不同类型的样本应该比较均衡：

| 类别 | 建议占比 | 样本数（基于1000总数） |
|------|----------|------------------------|
| 球形物体 | 20% | 200 |
| 圆柱形物体 | 20% | 200 |
| 平面物体 | 25% | 250 |
| 不规则形状 | 25% | 250 |
| 多点接触 | 10% | 100 |

## 实际操作建议

### 采集流程

1. **准备物品**
   - 准备至少 10-15 种不同形状的物体
   - 建议：弹珠、笔、橡皮、积木、硬币、钥匙、手指等

2. **启动采集**
   ```bash
   cd shape_reconstruction
   python data_preparation.py --auto_ref
   ```

3. **系统性采集**
   - 一种物体采集 50-100 个样本
   - 每种物体尝试不同位置、角度、力度
   - 不要太快，给系统时间捕获有效接触
   - 观察屏幕上的高度显示，确保数据有效

4. **采集节奏**
   - 接触 → 保持 1-2 秒 → 移开 → 换位置/角度 → 再接触
   - 不要快速连续按压（会产生大量相似样本）
   - 利用手动保存（'s'键）确保关键样本被保存

## 常见问题

### Q1: 采集多少数据才够？
**A**: 取决于应用场景：
- 概念验证：500 个
- 实际应用：1000-2000 个
- 高精度要求：3000+ 个

### Q2: 能不能用同一个物体采集所有数据？
**A**: 不推荐。模型会过拟合到这个特定物体，无法泛化到其他形状。

### Q3: 手动保存（'s'键）和自动保存有什么区别？
**A**: 
- 自动保存：检测到有效接触且与上次不同时自动保存（推荐日常使用）
- 手动保存：在特定时刻强制保存（用于捕获关键样本）

### Q4: 如果中途光照变化了怎么办？
**A**: 必须重新开始！光照变化会导致参考图像失效，数据质量严重下降。

### Q5: 可以用相同物体采集不同的数据集吗？
**A**: 可以，但要确保：
- 不同的接触位置
- 不同的接触角度
- 不同的接触力度

## 数据验证

采集完成后，应该：

1. **检查数据分布**
   ```bash
   python shape_reconstruction/check_dataset.py  # 如果有这个脚本
   ```

2. **检查样本质量**
   - 随机查看 10-20 个样本
   - 确保高度图有明显的形状特征
   - 确保差分图有清晰的接触区域

3. **数据统计**
   - 高度范围分布
   - 接触区域大小分布
   - 确保覆盖不同情况
